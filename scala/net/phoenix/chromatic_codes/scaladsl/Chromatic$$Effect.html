Effect

net.phoenix.chromatic_codes.scaladsl.Chromatic.Effect
final case class Effect(movement: String, palette: Vector[Int], colorRate: Float = ..., motionRate: Float = ..., playbackRate: Float = ..., settings: Map[String, Any] = ...)

Immutable effect configuration; native defaults and validation remain in MovementRegistry.

Constructor controls are effect-specific: motion can mean amplitude, spacing, size or another geometry control. Playback changes time independently. Explicit options override the same keys in a movement descriptor.

Value parameters

colorRate

effect-specific color control

motionRate

effect-specific geometry or movement control

movement

registered movement name or descriptor

palette

packed RGB palette, copied into this immutable description

playbackRate

independent animation-time multiplier

settings

supported per-effect options
