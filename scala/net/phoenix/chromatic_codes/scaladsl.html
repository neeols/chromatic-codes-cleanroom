object Chromatic

Scala 3 tools for choosing text effects and registering the names your text will use.

Scala 3 tools for choosing text effects and registering the names your text will use.

Import net.phoenix.chromatic_codes.scaladsl.Chromatic.*. The helpers call the same Java factories, parser registrations and temporary animation times used by the Java API. Keep the returned registration scope while your text needs its names; close it later to remove those entries. Their runtime is native Scalar for Scala 3. Ordinary Java/Kotlin consumers do not load this object and need not install Scalar solely because these optional helpers are included.

val codes = definitions("my_mod") { text =>
 text.color("gold", 0xFFCC00)
 text.effect("warm_wave", effect("wave", 0xFF4000, 0xFFD000).option("amplitudeY", 2.5))
}
// Draw "&[warm_wave]Hello§r" through Minecraft's normal FontRenderer.
// When your mod no longer needs these formatting names:
codes.close()

Native drawing still belongs on Minecraft's client thread. The common definition/factory helpers themselves do not require OpenGL. Effects remain shared callback objects; the DSL does not make mutable callbacks thread-safe.
